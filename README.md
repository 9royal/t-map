# T map v1.04.6 — 放大鏡準星內部與外島接觸修正版

臺灣行政區互動拼圖。本版只針對 `v1.04-testing` 的放大鏡判定修正：**中央準星小圓圈只要邊緣碰到，或中央點已進入正確行政區，就必須持續視為接觸；提示與最後吸附共用同一結果**。既有手機拖曳、頁面捲動、底圖提示分流、國語／台語朗讀、22 縣市／368 鄉鎮市區資料與 localStorage 進度格式不變。

## v1.04.6 本輪修正

- **修正「邊緣亮、進入內部反而不亮」**：中央點已位於正確行政區內時，無論距離邊界多遠，都持續視為準星接觸，放大鏡內保持高亮＋輪廓發光。
- **提示與吸附使用同一判定**：放大鏡 ON 時，最後放開是否成功吸附也由同一個準星小圓圈接觸結果決定；不再沿用 24／30px 寬鬆半徑，也不再用最近行政區做額外吸附。
- **中央點＋圓圈邊緣雙重接觸**：中央點是否在行政區內改用瀏覽器實際 SVG hit-test；若中央點尚未進入，才以約 **3.4 CSS px** 的圓圈邊緣距離判定接觸。這可避開 iPhone／iPad WebKit 對 SVG `isPointInFill()` 的差異。
- **外島同規則**：澎湖、金門、連江的獨立放大框也直接用其自身 SVG 做中央命中與邊緣接觸判定。
- **正確提示 OFF 不影響作答**：提示 OFF 時不亮黃，但只要準星圓圈確實接觸正確區域，仍可成功吸附。
- **放大鏡 OFF 維持既有規則**：手機不使用放大鏡時，原有小行政區智慧觸控容許區仍保留。
- **底圖提示規則不變**：放大鏡 ON 時，正確答案亮色只出現在放大鏡內；底圖不顯示正確答案亮色。
- CSS／主要 JS 資源版號更新為 `?v=1.04.6`。

## 觸控規則摘要

| 狀態 | 正確提示 | 最後吸附 |
|---|---|---|
| 放大鏡 ON＋提示 ON | 準星小圓圈碰觸正確區域時，僅放大鏡內亮黃 | 同一接觸條件成立才吸附 |
| 放大鏡 ON＋提示 OFF | 不亮黃 | 同一接觸條件成立仍可吸附 |
| 放大鏡 OFF | 沿用既有提示邏輯 | 沿用既有手機智慧容許區 |

## 保留功能

- 22 縣市與 368 鄉鎮市區；澎湖、金門、連江維持獨立放大框。
- 國語／台語朗讀、名稱顯示、正確位置提示、放大鏡開關、慶祝音效、深淺色主題。
- 手機三段式拼圖抽屜、拼圖圖形專用拖曳、地圖縮放／平移、點選放置。
- localStorage 使用 `tmap-v1-state`，更新不主動清除既有進度。

## 本機測試與建置

需 Node.js 20 以上，建議 Node.js 22：

```bash
npm install
npm test
npm run build
npm run verify
npm run preview
```

本版自動單元測試共 **24 項**，包含準星視覺半徑換算、提示／吸附共用接觸邏輯、既有幾何距離、手機 viewBox、抽屜與語音 profile。正式發布前仍需用 Cloudflare Preview 在實際手機／平板驗收。

## Cloudflare Pages

沿用同一 Repository 與 `https://t-map.pages.dev/`。建置設定維持：

| 欄位 | 設定 |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `npm run build && npm run verify` |
| Build output directory | `dist` |
| Root directory | 留空 |

此修正版請繼續部署在 `v1.04-testing` Preview 驗收，不要先合併到 `main`。
