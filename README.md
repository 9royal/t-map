# T map v1.05.8 — 東帝汶亞洲分類與部署修正版

v1.05.8 延續臺灣、中國省級行政區、世界第一層與各洲國家拼圖。本版針對實機測試修正世界國家名稱對比、洲別縮放、大洋洲拼圖範圍、紐西蘭／斐濟輪廓，以及海洋放置後錯誤大範圍變色。

## 2026-10-05 修正

- 已重現原 v1.05.8 的部署失敗：`npm run build` 成功後，`npm run verify` 回報「東帝汶應保留亞洲關卡」。
- 原因：實際 `countries-list 3.4.1` 的 `countries.TL.continent` 為 `OC`，舊測試資料卻設定為 `AS`。
- 明確覆寫東帝汶（TL）為亞洲，世界第一層與國家拼圖皆只保留在亞洲。
- 東帝汶從大洋洲完全移除；大洋洲固定 7 區，名稱如下。
- 世界圖資加入修訂參數，並調整圖資快取設定，避免更新後仍讀取舊分類。
- 使用真實套件與圖資完成 64 項測試、建置及部署驗證。版本號維持 v1.05.8。

## 本版重點

- 世界第一層仍使用 **D3 Equal Earth 等積投影**；北極海維持 v1.05.6 / v1.05.7 的主圖感應方式，不新增獨立放大框。
- 世界第一層已放置名稱改成高對比文字：
  - 淺色：深色字＋白色 halo。
  - 深色：白色字＋深色 halo。
- 七大洲第二層在 Equal Earth 下再依洲別增加適度 `scaleBoost`：
  - 非洲、南美洲放大幅度最大。
  - 亞洲、歐洲、北美洲、大洋洲也略為放大。
- 大洋洲改採固定 7 區教學白名單：
  - 澳洲
  - 紐西蘭
  - 巴布亞紐幾內亞
  - 索羅門群島
  - 萬那杜
  - 新喀里多尼亞
  - 斐濟
- 澳洲資料以 ISO2 / 名稱唯一鍵去重，避免同一拼圖重複出現。
- 紐西蘭只保留兩個最大主島 polygon（北島、南島）。
- 斐濟保留主要島嶼元件，並在拼圖片預覽使用大洋洲中央經線，避免跨 180° 經線時輪廓被拉扁。
- 東帝汶僅保留亞洲關卡；不列入大洋洲或「跨洲國家」說明。
- 大洋洲白名單外的國家／地區不再出現在目標地圖上，但會完整列於排除說明。
- 太平洋、大西洋、印度洋 polygon 在瀏覽器渲染前會檢查 D3 球面面積；若被解讀成反向 complement，會自動反轉 ring，避免放入太平洋後其他海洋也一起變色。

## 洲別 Equal Earth 投影設定

每一洲仍使用 Equal Earth，只調整中央經線、padding 與適度放大倍率。面積關係仍由 Equal Earth 維持。

| 洲 | 中央經線 | v1.05.8 scale boost |
|---|---:|---:|
| 亞洲 | 100°E | 1.06 |
| 歐洲 | 15°E | 1.08 |
| 非洲 | 20°E | 1.14 |
| 北美洲 | 100°W | 1.07 |
| 南美洲 | 60°W | 1.14 |
| 大洋洲 | 155°E | 1.05 |
| 南極洲 | 0° | 1.00 |

## 世界圖資

- 世界國家輪廓：`world-atlas` 2.0.2 / Natural Earth 4.1.0。
- 洲別 metadata：`countries-list` 3.4.1。
- 國名：ISO 3166-1 + T map 繁體中文名稱快照。

Natural Earth / world-atlas 的國界呈現依其資料來源與版本；T map 為地理學習用途，不自行宣告爭議領土主權。
