# T map v1.04 — 手機響應式與小行政區觸控優化版

臺灣行政區互動拼圖。v1.04 延續 v1.03 的桌機／平板版操作，不另做手機網站，也不更換網址；當視窗寬度小於等於 640px 時，自動切換手機操作介面。核心目標是避免把整張地圖單純縮小後，造成小行政區難以點選或拖曳。

## v1.04 手機模式

- **全寬地圖＋底部拼圖片抽屜**：手機不再把拼圖片與地圖上下長列堆疊。底部抽屜預設收合並提供橫向拼圖片；可展開成 2～3 欄清單。從展開抽屜選好拼圖後會自動收合，讓地圖重新取得主要畫面空間。
- **點拼圖 → 點地圖**：在手機版是正式主要操作之一，與拖曳同樣可完成拼圖。桌機和平板原本操作保留。
- **智慧觸控容許區**：真實 SVG 行政區形狀完全不放大、不扭曲。手指落在邊界附近時，縣市最多約 24 CSS px、鄉鎮市區最多約 30 CSS px 內會搜尋最近的實際行政區輪廓作為候選。若落在錯誤行政區附近，仍判定為錯誤，不會偷偷吸到正確答案。
- **局部放大鏡**：手機以觸控拖曳拼圖進入地圖時，手指上方顯示約 2.35 倍的圓形局部放大鏡，並同步目前碰觸色／正確提示色，降低手指遮住小行政區的問題。
- **手機地圖縮放**：主臺灣地圖與鄉鎮市區地圖支援雙指縮放；放大後可單指平移。另提供「－／重設／＋」按鈕。最大放大倍率約 4 倍，且不允許把地圖平移到原始範圍之外。
- **不洩漏答案**：縮放與平移不會自動把畫面移到正確位置。正確位置提示 OFF 時，只保留一般碰觸變色與觸控容許區；ON 時才在接近正確輪廓時顯示高對比光暈。

## 斷點與版面

| 寬度 | 介面 |
|---|---|
| 901px 以上 | 原桌機雙欄版 |
| 641～900px | 原平板單欄／大地圖版 |
| 640px 以下 | 手機操作版：全寬地圖、底部拼圖片抽屜、地圖縮放、智慧觸控與拖曳放大鏡 |

手機模式依 **CSS viewport 寬度** 判斷，不依賴裝置品牌或 User-Agent，因此手機橫向或窄視窗也能一致運作。

## v1.03 提示規則仍保留

| 操作 | 正確位置提示 OFF | 正確位置提示 ON |
|---|---|---|
| 碰觸任一未完成行政區 | 一般碰觸變色 | 同樣一般碰觸變色 |
| 碰觸錯誤位置 | 不透露答案 | 不透露答案 |
| 靠近正確位置 | 不顯示答案提示 | 正確輪廓以不同顏色、加粗及光暈提示 |
| 放到正確位置／有效容許範圍 | 自動吸附 | 自動吸附 |
| 放錯位置 | 保留拼圖，不扣分 | 相同 |

## 保留功能與資料

- 22 縣市與 368 鄉鎮市區；澎湖、金門、連江維持獨立放大框。
- 語音朗讀、名稱、正確位置提示、慶祝音效、深淺色主題。
- localStorage 仍使用 `tmap-v1-state`，更新版本不主動清除學生原有進度。
- D3 7.9.0、topojson-client 3.1.0、taiwan-atlas 2021.9.20 固定版本，在 Cloudflare 建置時複製進 `dist/`，學生端不需外部 CDN。
- 不新增登入、後端資料庫、排行榜或 API Key。

## 本機測試與建置

需 Node.js 20 以上，建議 Node.js 22：

```bash
npm install
npm test
npm run build
npm run verify
npm run preview
```

目前自動單元測試涵蓋提示 ON/OFF、幾何距離、觸控容許判定所需距離函式，以及手機 viewBox 的縮放／平移／邊界限制。正式發布仍需在 Cloudflare 預覽網址以實際 iPhone／Android 或瀏覽器裝置模擬器驗收觸控手勢。

## Cloudflare Pages

沿用同一個 GitHub Repository 與 `https://t-map.pages.dev/`，不需要新建 Cloudflare 專案。建置設定維持：

| 欄位 | 設定 |
|---|---|
| Production branch | `main` |
| Framework preset | None |
| Build command | `npm run build && npm run verify` |
| Build output directory | `dist` |
| Root directory | 留空 |

建議先建立 `v1.04-testing` 分支，由 Cloudflare Preview 驗收手機版，再合併到 main。詳細步驟見 `DEPLOYMENT_GUIDE.md`。

## 手機驗收重點

至少測試 360×800、390×844、430×932 三種常見手機 viewport，並檢查：底部抽屜收合／展開、選取後自動收合、點選放置、小行政區邊界附近觸控、錯誤位置不誤吸、ON/OFF 提示、拖曳放大鏡、＋／－／重設、雙指縮放、放大後平移、旋轉螢幕後介面恢復，以及完成後進度保存。

## API 與隱私

不使用 OpenAI、Gemini、Google Maps、Firebase 或其他需要 API Key 的服務，不需要後端資料庫。使用 Web Speech API、Web Audio API、Pointer Events、Fetch API（同網域靜態資料）與 localStorage。語音服務是否連網由瀏覽器／作業系統決定，T map 本身不傳送語音 API Key。
