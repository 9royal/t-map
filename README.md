# T map v1.05.9

本版加入拼圖文字避讓、亞洲不拼圖名單及跨洲國名標示，延續臺灣、中國省級行政區、世界第一層與各洲國家拼圖。

## 拼圖文字避讓

- 選取或拖曳拼圖片時，暫時隱藏已放置的地圖名稱，以及離島／放大框名稱。
- 放置成功、按「取消選取」、按 Esc 或離開關卡後恢復名稱；觸控取消或拖曳時視窗失焦也會清除拖曳。
- 名稱 OFF 時，恢復操作仍保持名稱關閉。
- 手機放大鏡內不顯示地圖文字。名稱 ON 時，目前拼圖片名稱另顯示於鏡外。
- 適用臺灣縣市、鄉鎮市區、中國省級行政區、世界第一層及各洲國家拼圖。

拼圖片、地圖文字、選取提示與中文／English 朗讀均使用對應洲別名稱。進度以原國名保存，保留舊版有效進度，新增排除區域的舊進度不再計入。

輪廓沿用既有處理：俄羅斯、土耳其、哈薩克與埃及依原規則顯示洲內部分；喬治亞、亞塞拜然因既有高加索洲界處理，在兩洲保留完整國形，名稱後綴表示本關洲別。

## 保留的地圖設定

- 東帝汶只保留亞洲，不出現在大洋洲或跨洲清單。
- 大洋洲固定 7 區：澳洲、紐西蘭、巴布亞紐幾內亞、索羅門群島、萬那杜、新喀里多尼亞、斐濟。
- 世界第一層及各洲國家拼圖使用 Equal Earth 等積投影；保留洲別縮放、國名高對比與海洋 winding 修正。
- 北極海沿用主圖感應方式。紐西蘭保留兩個主島，斐濟保留主要島嶼。
- 世界圖資使用修訂參數 `20261007-puzzle-labels`，避免沿用舊分類。

## 圖資

世界輪廓使用 `world-atlas 2.0.2`（Natural Earth 4.1.0），洲別 metadata 使用 `countries-list 3.4.1`；國名採 ISO 3166-1 與 T map 繁體中文名稱快照。臺灣使用 `taiwan-atlas 2021.9.20`，中國使用 `@svg-maps/china 2.0.0`。
